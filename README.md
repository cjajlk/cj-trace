# CJ Trace

Prototype WebXR simple pour afficher une image locale semi-transparente en réalité augmentée.

## Utilisation

1. Ouvrir le site dans un navigateur compatible WebXR `immersive-ar` (Wolvic sur PICO).
2. Choisir une image PNG, JPEG ou WebP locale.
3. Vérifier l’aperçu, puis sélectionner **Commencer**.

L’image choisie reste locale à l’appareil : elle n’est ni envoyée ni enregistrée sur le site.
